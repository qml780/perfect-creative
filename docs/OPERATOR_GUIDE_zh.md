# 中文运营手册

## 首次登录

启动网站后，在另一个 PowerShell 终端进入项目目录执行 `npm run admin:init`。输入邮箱与自选密码，然后访问 `/admin/login`。登录后，在「网站设置」可编辑品牌展示名和中英首页标题。

## 上架产品

1. 进入「商品 → 新增商品」，填写 SKU、名称、材质、中英文说明及 URL 标识。URL 标识使用小写字母、数字和连字符。
2. 选择随项目交付的素材，或上传 5 MB 内的 JPG／PNG。按已确认的资料填写规格、MOQ 与交期。
3. 先保存草稿。确认内容后在状态中选「发布」。用顾客端产品目录核对。要撤下时把状态改为「下架」。

## 跟进询盘

「询盘」显示客户公司、型号、数量、状态和负责人。打开单条记录后，可查看采购要求、下载随询盘上传的附件、录入负责人和内部报价备注。保存后可在「操作记录」查看变更。对外报价或确认收款前使用企业约定的人工流程。正式报价单、邮件及收款尚未接入。

## 回复客户消息

访客在首页、产品页或询价页右下角点击「在线咨询」。员工登录后进入「客服」，会话会收到即时更新。访客的原文先显示，本地机器翻译随后更新。输入中文回复后可点「预览译文」，核对数量、型号和条款后点击「确认译文并发送」。收到回复的访客可展开查看原文。
