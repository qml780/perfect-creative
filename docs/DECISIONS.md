# 技术决策

- 使用 Next.js 16.4.6 App Router，React、TypeScript 和版本锁定的 npm 依赖。按官方说明使用异步路由参数及 Route Handler。 [安装文档](https://nextjs.org/docs/app/getting-started/installation) [Route Handler 文档](https://nextjs.org/docs/app/getting-started/route-handlers)
- 使用独立 CSS 变量和原生组件绘制品牌界面。中英使用系统回退字体和同一套路由模板。页面导航采用文档跳转，使渐进增强脚本每页重新绑定。在目标浏览器中可用原生表单与链接。
- Oneso 的吸顶分组导航、页内揭示、横滑画廊和主题面板应用在独立站中。拆装面板从 URL 读取状态，并支持点击、刷新和历史回退。移动端菜单维持一个入口，避免在小屏挤占语言与询价按钮。
- 九张随需求提供的图片保存为 JPEG 以减少传输体积。暖色背景由页面样式处理。包装稿为原创结构示意，具体组装和纸箱参数由经营者确认。
- 本地使用 Node 自带 SQLite。数据库连接按请求开启，启用外键与 WAL。临时所有者密码使用带盐 scrypt，Cookie 存储随机会话，仅数据库保存其哈希。管理操作同时检查来源及服务端身份。
- 询盘提交使用 Zod 校验、原子入库、文件大小和签名检查及本地限流。附件由所有者登录后下载。生产场景需要服务端流式大小限制、持久化限流和对象存储。
- 所有展示型号均标为演示，价格和未核实的规格不对客户作承诺。支付端点当前拒绝结账。生产模式禁用本地数据库与员工登录。
