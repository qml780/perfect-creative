# 开发与验收记录 · 2026-11-17

## 3D 展示更新 · 2026-11-22

- **实现** 首页入口与独立 3D 区域。按产品图片搭建台面、前板、开槽侧板、置物层、底座及紧固件，支持旋转、缩放、四种材质、视角预设、板件展开与重置。页面标明模型的示意用途。
- **加载** 自托管 Three.js 模块，进入视口后加载。WebGL 或下载失败时展示产品照片并提供重试。离开视口后暂停渲染。
- **验证** 7 项端到端测试、Lint、TypeScript 与生产构建通过。静态展示在仓库子路径下验证材质、展开动画、768 px 布局、390 px 双指缩放、滚轮继续滚动页面，以及无浏览器异常。

## Phase A · 品牌前台

- **状态** DONE（本地演示）
- **实现** 黑白主色、冷灰产品背景和钴蓝交互控件。桌面首页将产品图放到左侧，英文标题采用 Instrument Serif。材质区保留黑色亮面边缘和透明连接处特写。每段滚入视口后整段标题先出现，正文随后出现。询价页采用上方标题区和下方表单。
- **验证** 375、768 和 1440 px 视口无横向溢出，移动菜单支持 Escape 与焦点恢复。轮播切换同步圆点。拆装面板支持 URL 直达、刷新和回退。手动检查桌面原生平滑滚动与吸顶导航。

## Phase B / C · 本地运营与询盘

- **状态** PARTIAL
- **实现** SQLite 持久化、开发环境所有者登录、会话注销、服务端权限检查、商品草稿/发布/下架、商品上传、首页标题管理、询盘与私有附件入库、分配负责人、跟进状态与审计。
- **验证** 未登录访客无法写入后台或读取私有附件。询价会预选产品，提交返回随机编号，员工可查附件和跟进。商品发布后可见，下架后详情返回 404。未定价产品不能结账。
- **缺口** Supabase、正式员工权限与 MFA、正式报价、客户档案和邮件。[交接缺口](handover.md)

## Phase D–G · 外部服务与上线

- **状态** PARTIAL
- **当前状态** 本地客服经服务器发送事件即时推送，自动翻译采用本机 Argos，支持英、中、马来语。原文先到，译文随后更新，同一条消息原文和译文均保存到 SQLite。
- **后续** 接正式数据和身份后补齐报价、客服推送与通知、模拟订单和 PayPal 沙箱，再推进物流、分析与生产验收。
