# 生产上线清单

- [ ] 经营者确认品牌、登记主体、营业资料、真实联系方式及可使用的客户标识图片。
- [ ] 校对 SKU、板厚、尺寸、毛重、MOQ、交期、包装与装配手册。换下演示编号。
- [ ] 接入正式目录与询盘数据层，启用员工邀请、MFA、角色隔离、权限测试和审计。
- [ ] 接入上传隔离、文件安全处理、服务器限流、访问日志脱敏及数据库备份恢复。
- [ ] 准备隐私、运输、交易与售后政策，并核对经营地区的相关要求。
- [ ] 确认域名与 HTTPS。分别从目标国内和海外网络检查图片加载、页面延迟和表单响应。
- [ ] 在各收款方式完成商户审核、物流条款和沙箱验证后，逐项启用正式收款。
- [ ] 验证经授权的邮件投递、客服语言流程和分析配置是否符合实际运营需求。
